# AI-GUIDE: ShotgunMetal BAR-бот

Полная инструкция, чтобы вносить правки по стилю игры БЫСТРО, без перечитывания кода.
Это гид для AI-ассистента. Читай ДО правок. Цель — не разбираться каждый раз, а сразу знать, где что менять.

---

## 1. Что это такое

Автоматический бот для (Beyond All Reason). Это **клиентский виджет** (LuaUI Widget), а не мод/Gadget.
Играет сам: строит базу, экономику, воеводы, воюет как ИИ.

**Ключевые настройки логики — в `config.lua`** (209 строк). Стиль игры меняется почти всегда ТОЛЬКО там, твиками чисел. Это первый файл для правки по стилю.

## 3. Целевой стиль игры (текущая задача)

- Старт: **4 ветра вплотную → 1 mex → bot lab** (сразу фабрика).
- `uniform-Metal` карты: в `Game.metalMap` нет спотов для мексов → мексы ставят по металнистости, не по `st.metalSpots`.
- **Эко-ряды строго 2×4 = 8 зданий, компактно у базы** (НЕ длинные линии).
- Не спамить eco/mex бесконечно — ограничено капами.
- **Экстренная реакция на сталл** металла/энергии (строить добычу).
- Не блокировать проходы и выходы фабрик; разваливать (рекламить) здание, застрявшее на выходе.
- Скауты (до 4) с патрулём перед базой.
- Много юнитов держатся у базы (оборона), остальные атакуют.

## 4. Терминология/ловушки (ВАЖНО)

- **Ветра (`corwin`) в BAR имеют `energyMake = 0`** — энергию дают через поле `windGenerator`. Поэтому счётчик eco в `economy.lua:626-628` проверяет `(energyMake>0) or (windGenerator>0)`. НЕ считай ветер по имени или по `energyMake`.
- `st.mexUnitCount` / `st.ecoEnergyCount` — счётчики построенного.
- `st.unclaimedMexCount` — свободные ещё мекс-точки (на uniform-metal = 0).
- `st.myFactoriesCount`, `st.pendingFactoryBlueprints` — готовые и строящиеся фабрики.
- `st.metalStalling`, `st.energyStalling` — флаги сталла (из economy.lua).
- `ecoRowsReady` — true когда достаточно eco, включает длинные ряды (но теперь кап 8).
- Eco «считается по полям юнита», не по имени — менять осторожно.

## 5. Цепочка «фабрика → юниты → куда ехать» (orders.lua)

Один файл решает всё построчно. Главные блоки:

1. **Выбор, что строит фабрика** (orders.lua:272-460).
   - `unitsAllowed` (278-280): юниты разрешены после `MIN_CONS_BEFORE_UNITS` консов ИЛИ раньше при `frame >= UNIT_RUSH_FRAME / AGGRESSION`.
   - `agr = max(0.25, AGGRESSION)` (283) — мастер-узл флоуда юнитов.
   - `targetDefenders` (297): сколько оборонных юнитов минимум. Сейчас 8 (12 при рейдерах).
   - Приоритет выбора: **конструирующий → дешёвый боевой → скаут → саппорт → боевой**. Вероятность конса = `CONS_ORDER_CHANCE / agg` (359) — выше агрессия → реже консы, больше бойцов.
   - `conTarget` (355): желаемое число консов.

2. **Эко-блок** (orders.lua:1198-1356): если мало металла/энергии — строитель строит мекс/ветер/солар.
   - `ECO_BUILD_RADIUS=120` — компактный блок 2×4.
   - Жёсткий кап `ECO_BLOCK_BUILDINGS=8`: свыше 8 eco-зданий в блоке строитель не строит eco (orders.lua ~1203-1219), чтобы не рос третий ряд.
   - Ветры/мексы ставятся в ряд через `QueueEcoRow` (orders.lua:1063) — 2 ряда × `ECO_ROW_COUNT`.

3. **Деплой боевых юнитов** (orders.lua:2650-2786) — финал функции:
   - `homeGuardUnit` (2670): юнит остаётся у базы, если `unitID % HOME_GUARD_MOD == HOME_GUARD_KEEP % HOME_GUARD_MOD`. Сейчас MOD=2, KEEP=1 → **каждый 2-й юнит — дом-гвард**.
   - `hgR2` (2671): квадрат радиуса, дальше которого дом-гвард не гоняется (`HOME_GUARD_RANGE` × baseRadius). Сейчас 9.
   - Если враг в радиусе — атака/позиция (`FindBestClusterTarget`, orders.lua:2674).
   - Если армия атакует (`army.state=="attacking"`): дом-гвард остаётся, если цель далеко от базы (2715-2727); иначе шлёт на цель.
   - **Враг неизвестен** → встать на периметр-кольцо ВОКРУГ базы (2764-2783). `ringR` = расстояние кольца (`PERIMETER_SLOTS` слотов). Сейчас `ringR = max(350, min(baseRadius*0.9, 700)*scale)` — близко к базе.
   - Враг найден → дом-гвард (~половина) стоит на кольце, остальные атакуют фронт (`PushFrontier`).

## 6. config.lua — все рычаги стиля (и что делают)

Меняй числа здесь, чтобы сменить поведение. Мини-справочник:

### Экология/темп строительства
- `OPENING_WIND_SPACING=32` — как близко открывающие ветры к друг другу (вплотную).
- `ENERGY_GRID_SPACING=64`.
- `ECO_BUILD_RADIUS=120` — мало, блока 2×4.
- `ECO_ROW_COUNT=4` — длина ряда (2 ряда × 4 = **8 зданий**).
- `ECO_BLOCK_BUILDINGS=8` — жёсткий кап eco-зданий в блоке (не больше 2×4).
- `ECO_BUILDER_AGGRESSION=2` — множитель бюджета строителей eco (не юнитов!).
- `ROWS_MIN_MEX=3`, `ROWS_MIN_WIND=10` — порог включения рядов eco.
- `MIN_CONS_BEFORE_UNITS=2` — сколько консов фабрика делает ДО первых боевых юнитов.

### Производство/флоуд юнитов
- **`AGGRESSION=7`** — мастер-узл. Выше = реже конструкторы, раньше раш, больше бойцов. Ниже (<1) = жадная eco. «Сделай бота агрессивнее» = поднять сюда.
- `CONS_PER_FACTORY_POST=4`, `CONS_BASE_POST=7`, `CONS_ORDER_CHANCE=0.7` — конструционное население.
- `UNIT_RUSH_FRAME=4500` — (~2.5 мин) с этой минуты фабрики жмут бойцов.
- `HEAVY_UNLOCK_ARMY_SIZE` — когда включаются тяжёлые юниты.
- `T2_MIN_ARMY=20`, `T2_MIN_FACTORIES=3`, `T3_MIN_ARMY=80` — пороги тех-переходов.
- `SCOUTS_PER_FACTORY=1` — сколько скаутов на фабрику.

### Оборона / «держаться у базы»
- **`HOME_GUARD_MOD=2`**, `HOME_GUARD_KEEP=1` — доля армии что остаётся у базы. MOD=2 → каждый 2-й (половина). MOD=3 → треть. Уменьши MOD → больше дома.
- `HOME_GUARD_RANGE=9` — × baseRadius: как далеко от базы дом-гвард гоняется за целями.
- `PERIMETER_SLOTS=24` — слотов на кольце обороны вокруг базы (пока враг не найден).
- `targetDefenders` (в orders.lua:297) — минимум оборонных юнитов, не в config.

### Прочее
- `ANTI_CLUMP_MIN=220`, `ANTI_CLUMP_MAX=650` — как широко разводить юнитов (не кучей).
- `RETREAT_HEALTH_RATIO` — при каком HP юнит отступает.
- `MEX_SKIP_DIST=1000`.
- `CMD_*`, `GetMexGain`, `GetEnergyGain`, `GetEngageRange` — вычисляемое в config.

## 7. «Мне нужно изменить стиль» — какую кнопку жать

| Хочу | Куда ставлю |
|------|-------------|
| Больше юнитов / реже консы | Поднять `AGGRESSION` |
| Раньше начинать воевать | Уменьшить `UNIT_RUSH_FRAME`, увеличить `AGGRESSION` |
| Меньше/больше юнитов ДОМА у базы | `HOME_GUARD_MOD` (меньше=больше дома) |
| Обороны теснее к базе | Уменьшить `HOME_GUARD_RANGE`, `PERIMETER_SLOTS`, `ringR` в orders.lua:2773 |
| Больше оборонных юнитов вообще | `targetDefenders` в orders.lua:297 |
| Eco-ряды короче/длиннее | `ECO_ROW_COUNT`, `ECO_BLOCK_BUILDINGS` |
| Eco-ветры/мексы вплотную | `OPENING_WIND_SPACING` |
| Быстрее расти эконом | `ECO_BUILDER_AGGRESSION`, снизить `AGGRESSION` |
| Меньше/больше скаутов | `SCOUTS_PER_FACTORY` |

## 8. Как вносить правку (пайплайн)

1. Найди нужный рычаг (таблица §7). Обычно это правка числа в `config.lua`.
2. **Измени файл в папке виджета**: `data\LuaUI\Widgets\ShotgunMetal\...`
3. **Проверь синтаксис** линтером:
   `node "C:\Users\P\AppData\Local\Temp\opencode\luacheck\syntax_check.js" <путь>.lua`
   Должно вывести `syntax OK`.
4. **Скопируй изменённые файлы** в git-репо:
   `C:\Users\P\GitHub\ShotgunPiuPiu-Metal-Bot\ShotgunMetal\`
5. `git add -A`, `git commit -m "..."`, `git push origin main`.
6. Воспользуйся в игре `/luaui reload`, дай пройти 1-2 минутам, посмотри `data\infolog.txt` по тегам `[ECO]`, `[EXIT-RECLAIM]`, `[SCAN]`.

**Виджет работает по фактическим файлам в папке виджета** — правь именно туда, потом копируй в git (не наоборот).

## 9. Правила стиля для AI-ассистента

- Отвечать ТОРОПКИЕ (2-3 предложения), без рассуждений/преамбул.
- Перед правкой стиля — смотреть `config.lua`, не переписывать логику в `orders.lua` без нужды.
- Менять стиль игры числом, не алгоритмом, где можно.
- Не ломать eco-счёт по полям (`energyMake`/`windGenerator`).
- Не создавать бесконечных спамов eco: держать капы.
- Карта uniform-metal: Nе полагаться на `st.metalSpots`.
- Валидировать синтаксис каждый раз; коммитить в git-репо.
- git-репо: https://github.com/ShotgunPiuPiu/BAR-MetalBot.git (ветка main).
